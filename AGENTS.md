# ATURAN GIT

- Pengecekan sinkron (`git fetch`) dilakukan **sekali saja** saat pertama kali bekerja di repo ini. Pastikan branch lokal sinkron dengan origin sebelum mengubah apa pun, dan laporkan jika berbeda. Jangan ulangi pengecekan di setiap tugas atau perintah; ulangi hanya jika saya menyebut bahwa saya berganti perangkat, atau jika push ditolak karena riwayat berbeda.
- Branch selain `main`: boleh langsung commit DAN push. Jangan meninggalkan commit lokal yang belum di-push.
- Branch `main`: JANGAN commit atau push ke `main` tanpa konfirmasi dari saya terlebih dahulu. Merge ke `main` dilakukan lewat PR yang saya setujui.
- Sebelum push pertama di repo ini, periksa workflow: pastikan push ke branch selain `main` tidak men-deploy ke produksi. Jika ada kemungkinan deploy dari branch lain, hentikan dan tanyakan dulu.
- Pesan commit singkat dan bermakna dalam bahasa Inggris.
